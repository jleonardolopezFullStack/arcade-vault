## Stack

Next.js 16.3.3 (App Router) · React 19.2.8 · TypeScript strict · Tailwind CSS v4 (PostCSS plugin, no `tailwind.config`). Import alias `@/*` → repo root.

Next 16 / Tailwind 4 specifics already visible in the scaffold — follow them instead of older patterns:
- Route component props come from **globally generated types**: `LayoutProps<"/">`, and the equivalents for pages/route handlers. Don't hand-write `{ children }: { children: React.ReactNode }`.
- Theme lives in `app/globals.css` via `@import "tailwindcss"` + `@theme inline`, not a JS config file.
- `AGENTS.md` is machine-generated by `next dev`; commit it with your changes rather than reverting it.

## Design prototype — the spec source

`iISLvhOSlu40WkgeVXdW_resources/resources/templates/` holds a standalone, runnable HTML/JSX mockup of the full product (React 18 UMD + Babel-standalone in the browser, no build). It is untracked and **not** part of the Next app — treat it as the visual and behavioral reference when implementing screens, and port from it rather than editing it.

Screens map to routes to build (names are Spanish, mirroring the prototype files):
- `biblioteca.jsx` — game library / catalog
- `detalle.jsx` — game detail
- `reproductor.jsx` — game player with HUD (score, lives, level, pause); gameplay is currently faked with a timer
- `auth.jsx` — login/signup
- `salon.jsx` — hall of fame / leaderboard
- `nav.jsx` — top nav, `app.jsx` — hash-based router + session/score persistence in `localStorage` (`av_user`, `av_scores`)
- `data.jsx` — `GAMES` mock array (id, title, short/long copy, cat, cover, color, best, plays)
- `styles.css` — the neon-retro theme: CSS custom properties (`--bg`, `--cyan`, `--magenta`, `--yellow`, `--green`, `--gold`…), `Press Start 2P` for display and `JetBrains Mono` for body
